# YouTube adapter — from SOCIAL/PLATFORM_STRATEGY.md

Shorts for discovery; 8–15 minute story/travel videos for deeper content.
Build recurring series.

## Input
Finished prompt pack: video/photo prompt + caption set + hashtags + CTA.

## Output
- **Shorts**: 9:16, ≤60s, title = hook line (≤60 chars), 3–5 hashtags in
  description, pinned comment carries the CTA.
- **Long-form** (weekly concept from the 365-day engine): title + description
  template, chapters from story beats, series playlist placement.
- Posting checklist per long-form quality bar.

## Series home
YouTube is the archive: every series gets a playlist; episode-tracker
`post_url` values feed the playlist order.
