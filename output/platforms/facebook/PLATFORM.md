# Facebook adapter — from SOCIAL/PLATFORM_STRATEGY.md

Prioritize Reels, relatable posts, photo stories and audience questions.
First seconds visually clear; captions easy to understand.

## Input
Finished prompt pack: video/photo prompt + caption set + hashtags + CTA.

## Output
- **Reels**: 9:16, hook in first 2 seconds, `caption_short` + 3–5 hashtags,
  CTA as first comment or end-card line.
- **Page posts** (photo): `caption_full`, 3–5 hashtags inline, CTA last line.
- **Stories**: reshare of the Reel with a question sticker when CTA is `comment`.
- Posting checklist: ratio, safe zones, sound-on assumption, no banned elements.

## Posting slot
From `output/calendar-365/calendar.yaml` — Facebook gets its own daily slot;
cross-posts staggered, never simultaneous with Instagram.
