# Instagram adapter — from SOCIAL/PLATFORM_STRATEGY.md

Prioritize Reels, carousels/photos, Stories, concise captions. Visual identity
consistent everywhere.

## Input
Finished prompt pack: video/photo prompt + caption set + hashtags + CTA.

## Output
- **Reels**: 9:16, `caption_short`, 8–12 hashtags (first comment preferred),
  CTA matched to goal (comment/share/save).
- **Posts**: 4:5 or 1:1 per photo category, `caption_full`.
- **Stories**: vertical cutdown; poll/question sticker when the CTA is `comment`.
- Posting checklist per visual-identity rules.

## Posting slot
From `output/calendar-365/calendar.yaml` — staggered against Facebook.
