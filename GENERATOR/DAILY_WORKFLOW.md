# DAILY GENERATION WORKFLOW

1. Read CHARACTER/CHARACTER_LOCK.md.
2. Read CHARACTER/CHARACTER_SHEET.md.
3. Select a country/location.
4. Select a content pillar.
5. Select activity.
6. Select emotion.
7. Add conflict or curiosity.
8. Add twist/payoff.
9. Check recent concepts for duplication.
10. Generate prompt.
11. Generate title/caption/hashtags/CTA.
12. Save episode number and continuity notes when it belongs to a series.
13. Publish according to the platform's current limits and quality requirements.
14. Record the concept so the next request can avoid duplication.

## Quality gate
Reject a concept if:
- character identity is unclear
- the hook takes too long
- the story has no reason to continue watching
- the ending has no payoff
- the CTA is generic every time
- it duplicates a recent concept
- the location claim would be misleading
