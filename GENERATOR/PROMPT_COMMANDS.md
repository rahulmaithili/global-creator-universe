# PROMPT COMMANDS

Use these commands whenever this repository is provided as the character/content source of truth.

## VIDEO
VIDEO: [location] | [topic] | [mood] | [duration]

Example:
VIDEO: Dubai | luxury cruise | funny | 30 sec

Return:
- unique concept
- 0–2 sec hook
- complete generation prompt
- dialogue
- ending
- caption
- hashtags
- CTA

## PHOTO
PHOTO: [location] | [topic] | [mood]

Example:
PHOTO: London | rainy coffee shop | cinematic

Return:
- complete image prompt
- title
- caption
- hashtags
- CTA

## NEXT VIDEO
Generate a new concept that does not repeat the immediately previous concept.

## NEXT PHOTO
Generate a new image concept with the locked character.

## REMAKE
REMAKE: [concept]
Create a materially different version while preserving character identity.

## SERIES
SERIES: [topic] | episode [number]
Create a connected episode with continuity and a new hook.

## DAILY PACK
DAILY PACK: [number of videos] videos + [number of photos] photos
Generate a balanced day across lifestyle, food, travel, adventure and engagement content.

## TREND ADAPT
TREND ADAPT: [trend description]
Rebuild the underlying format as an original character story. Do not copy another creator's exact execution.

## GLOBAL
GLOBAL: [topic]
Select an appropriate USA/UK/Gulf/global location and create an internationally understandable concept.

## Character rule
Every command inherits CHARACTER/CHARACTER_LOCK.md.
