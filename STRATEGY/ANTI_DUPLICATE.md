# ANTI-DUPLICATE SYSTEM

Before generating a new concept, compare it mentally against recent concepts.

Avoid repeating the same:
- location
- activity
- food
- outfit
- hook
- dialogue
- camera composition
- emotional beat
- twist
- CTA
- caption wording
- story structure

## Variation matrix
If a location repeats, change at least three major elements:
location sub-area + activity + story conflict.

If an activity repeats, change:
country + environment + emotional tone + ending.

If a food repeats, change:
restaurant type + camera angle + social situation + story.

## Continuity
For series content, continuity is intentional and should not be treated as duplication.

## Output quality
Originality is more important than generating filler. Unlimited generation means an unlimited combination system, not repeated copies.
