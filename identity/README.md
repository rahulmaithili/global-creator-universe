# IDENTITY layer

Platform-specific public identity. The core character and brand identity live
in the Brand Bible and stay platform-agnostic; each platform gets its own
section here because profile mechanics, audiences, and posting systems differ.

## Sections

- `facebook-identity/` — the new Facebook creator profile: setup, bio,
  profile-photo rules, cover rules, audience targeting, posting system.

Future: `instagram-identity/`, `youtube-identity/` — same structure, so the
brand reads as one person everywhere.
