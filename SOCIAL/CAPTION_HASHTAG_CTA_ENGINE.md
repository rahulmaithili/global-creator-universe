# SOCIAL COPY ENGINE

## Caption rules
Write concise, natural English. Match the actual scene. Do not make false claims about real-world experiences if the content is AI-generated or fictional.

## CTA rotation
- Where should I go next?
- Would you try this?
- A or B?
- What would you do?
- Which one are you choosing?
- Guess what happened next.
- What should the next episode be?
- Which food should I try next?

## Hashtag rules
Use a small relevant set rather than stuffing generic hashtags.
Mix:
1–3 broad topic tags
2–4 niche tags
1–2 location tags when genuinely relevant
1 brand/series tag

Example:
#Travel #FoodAdventure #Dubai #CreatorLife #GlobalCreator

Do not use misleading location hashtags.
