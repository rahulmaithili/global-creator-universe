# Global Creator Universe

Permanent source-of-truth for a global creator content system.

## Mission
Create unlimited original short-form videos, photos, stories and lifestyle content around one locked main character while changing locations, activities, outfits, stories and situations.

## Target
Primary: USA
Secondary: UK
Expansion: UAE, Saudi Arabia, Qatar, Kuwait, Bahrain, Oman and global English-speaking audiences.

## Core rule
CHARACTER IDENTITY STAYS CONSISTENT. WORLD, STORY, OUTFIT, LOCATION AND ACTIVITY MAY CHANGE.

## Quick Commands
- VIDEO: <location> | <topic> | <mood> | <duration>
- PHOTO: <location> | <topic> | <mood>
- NEXT VIDEO
- NEXT PHOTO
- REMAKE: <concept>
- SERIES: <topic> | episode <number>
- STORY: <topic>
- TREND ADAPT: <trend description>

## Every generated package should contain
Video: master prompt + hook + dialogue + shot/action direction + ending + engagement CTA + caption + hashtags.
Photo: image prompt + title + caption + hashtags + CTA.

## Anti-duplicate
Never repeat the same combination of location, activity, hook, dialogue, camera composition and story beat unless the user explicitly asks for a remake.

See CHARACTER/ for identity rules, STRATEGY/ for the content engine, VIDEO/ and PHOTO/ for generation rules, and SOCIAL/ for publishing copy.
