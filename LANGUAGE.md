# Language Rule (absolute)

All content generated for the Global Creator Universe is **English only**.

- Video prompts, dialogue, titles, captions, hashtags, CTAs, story text,
  image prompts, daily packs — everything is written in English.
- No Hindi, no Hinglish, no mixed-language lines anywhere in generated
  content. Not in chat replies about the content either, unless the user
  explicitly asks for another language for a specific item.
- This rule overrides any earlier language habit. Set by the user 2026-09-27.
